# Judging Criteria — Green Screen Séance

Kiroween 2026 judges score on five criteria. Keep these in mind for every decision.

## 1. Potential Impact
Solves a real, expensive problem (legacy mainframe modernisation). Pitch: conversational, no rewrite, open source. Prefer depth of impact over novelty-for-its-own-sake.

## 2. Technological Implementation
Use Kiro's own features for real reasons — not as decoration: specs, agent hooks, steering docs, MCP, property-based tests, Kiro Crew. Strongest story: Kiro using our MCP server to drive the green screen during development.

## 3. Design
Polished, memorable, haunting-but-usable UI. The split-screen green terminal + séance chat + planchette pointer is the signature. Accessibility: keyboard-only, reduced-motion, WCAG AA.

## 4. Innovation
`spirit-map` (auto-discovery → generated business-level tools) is the innovative core. The conversational bridge to a real legacy system without rewriting it is the differentiator.

## 5. Presentation
The demo writes itself: a modern chat window talking to a glowing green terminal. Keep a journal of how Kiro was used (screenshots + surprises) for the write-up and blog. Run the spec-vs-vibe-coding comparison the judges ask about.

## Build priority
Prefer a **complete, polished end-to-end experience** over breadth. One demo app, ~5 screens, done really well. The demo path must work three times in a row.
